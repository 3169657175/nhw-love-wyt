# ❤️ 牛昊文 × 温依婷 · 恋爱陪伴空间

一个完全运行在浏览器里的情侣陪伴网页：保留原来的浪漫大转盘，同时加入每日状态、陪伴计划、约会灵感、深度话题、时光盒、积分与连续打卡，让它不只是“抽一次奖”，而是可以长期使用的小型陪伴空间。

## 在线访问

- GitHub Pages：<https://3169657175.github.io/nhw-love-wyt/>
- GitHub 仓库：<https://github.com/3169657175/nhw-love-wyt>

无需安装、无需注册，手机和电脑浏览器都可以直接打开。

## 这次全量升级

### 🎡 浪漫大转盘

原有核心玩法完整保留：

- 12 项夸张陪伴权益，从半小时、今晚、周末一直到“一辈子”“三生三世”。
- 转盘动画、跑马灯、爱心背景、礼花与 Web Audio 音效。
- 中奖后生成恋爱陪伴权益公证书。
- Canvas 高清导出公证书海报。
- 开奖历史本地保存。
- 原有隐藏彩蛋与必中玩法继续保留。

### 💗 今日状态

每天可以记录：

- 当前心情：甜蜜 / 疲惫 / 想聊天 / 想约会 / 有点烦。
- 今日精力 1～10。
- “我现在更需要”的一句话。

每日首次保存领取 5 个心动积分；重复更新状态不会重复计算积分。

### ✅ 今日陪伴计划

根据当天心情自动给出 4 个可执行的小动作，例如：

- 主动拥抱。
- 放下手机认真聊天。
- 确定下一次约会时间。
- 一起完成一件低成本的小事。

支持：

- 完成 / 取消完成。
- 自定义任务。
- 把约会灵感一键加入今日计划。
- 当日进度条。
- 累计完成统计。

### 🍓 约会灵感引擎

不再只给“去哪玩”的泛泛建议，而是可以按照：

- 可用时间：30 分钟 / 1 小时 / 2 小时 / 半天。
- 预算：低 / 中 / 高。
- 当天心情。

筛选真正能够执行的安排，并支持：

- 换一条。
- 加入今日计划。
- 复制安排直接发给对方。

### 💬 深度话题胶囊

内置多组适合情侣认真聊天的问题，用来替代反复的“在干嘛”。

支持随机换题和一键复制。

### 📮 时光盒

可以记录今天值得记住的一句话、一个瞬间或一件小事。

- 最多保存 12 条。
- 自动记录时间。
- 与其他陪伴数据一起保存在浏览器本地。

### 💓 陪伴数据中心

把日常使用变成可见的长期记录：

- 心动积分。
- 累计打卡天数。
- 累计完成小事。
- 时光记录数量。
- 连续陪伴天数。
- 最近 7 天打卡状态。

积分规则：

- 每日首次状态打卡：+5。
- 完成一项陪伴任务：+10。
- 每次抽奖：+2。

### 💾 本地数据与迁移

所有私人内容默认只存在当前浏览器的 `localStorage` 中，不上传服务器。

支持：

- 导出完整 JSON 备份。
- 在其他设备/浏览器导入备份。
- 单独清空陪伴数据。
- 开奖历史与陪伴状态一起备份。

因此 GitHub Pages 只负责提供静态网页，不保存聊天、心情、时光记录等私人数据。

## 技术实现

整个项目依然保持“零构建”：

```text
index.html
README.md
```

主要使用：

- HTML5
- CSS3
- 原生 JavaScript
- Canvas
- Web Audio API
- localStorage
- Blob / File API

没有 React、Vue、Node 后端或数据库依赖，所以非常适合 GitHub Pages 静态托管。

## 本地运行

直接双击 `index.html` 即可。

也可以启动任意静态服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/
```

## 数据说明

浏览器本地数据主要包括：

- 抽奖历史。
- 每日心情、精力与需求。
- 今日陪伴任务。
- 打卡日期。
- 完成任务累计数。
- 时光盒记录。
- 约会筛选状态。

更换浏览器、清除站点数据或换设备前，建议先使用网页里的“导出数据”。

## 发布

仓库的 `main` 分支直接作为 GitHub Pages 静态站点来源。提交并推送 `index.html` 后，GitHub Pages 会自动更新公开页面。
